## Hypothese (terughoudend gemaakt)

Tekst-eigen feiten. **Genesis 28:10-22** beschrijft Jakob's vertrek van Beerseba naar Charan (vlucht voor Ezau). Onderweg overnacht hij in Bethel + ontvangt droom-visioen van **`sullam`** (H5551 — ladder) met **`malakhei elohim olim ve-yordim bo`** (engelen Gods op- en neerklimmend daarop) + JHWH-belofte. **Genesis 32:22-32** beschrijft Jakob's worsteling met **`ish`** (H376 — man) bij Pniel + naamsverandering Yaaqov → Yisrael. **Genesis 35:1-15** beschrijft Jakob's terugkeer naar Bethel + JHWH-bevestiging-belofte + naamsverandering-bevestiging. **Bron-eigen Bethel-inclusio**: vertrek (Gen 28) ↔ terugkeer (Gen 35).

NT-eigen typologie-claim. **Johannes 1:51** noemt Jezus' eigen typologische uitspraak `apartē tou nyn opsesthe ton ouranon aneōgota kai tous angelous tou theou anabainontas kai katabainontas epi ton huion tou anthrōpou` — bron-eigen woord-voor-woord-citaat van Gen 28:12 ladder-engelen-formule, **met expliciete identificatie van Mensenzoon als ladder-vervanging**. **N1 expliciete christologische identificatie** binnen NT-tekst zelf.

Interpretatieve framings. Dat de Bethel-Pniel-Bethel-cyclus typologisch model is voor reis-bekering-terugkeer-pad: **N2 structurele afleiding**, geen NT-tekst legt deze brug expliciet. Dat de Pniel-naamsverandering Yaaqov → Yisrael typologisch model is voor wedergeboorte-typologie: bron-eigen feit, **N3-clue** voor specifieke "geboorte van boven"-typologische uitwerking buiten Gen-eigen-context.

## Voorkomens (per cluster)

### Cluster A — Gen 28:10-22 vertrek-Bethel + ladder-droom [N1]

**Genesis 28:10-11** [N1] — `va-yetze Yaaqov mi-Beer Sheva va-yelekh Charanah va-yifga ba-maqom va-yalen sham` (Hc/H3318 + H3290 + Hm/H884 + Hc/H3212 + H2771 + Hc/H6293 + Hb/Hd/H4725 + Hc/H3885). Jakob vertrekt + komt aan op `ha-maqom` (de plaats — H4725).

**Genesis 28:12** [N1] — translit `va-yachalom ve-hineh **sullam mutzav artzah ve-rosho maggia ha-shamaymah** ve-hineh **malakhei elohim olim ve-yordim bo**` (Hc/H2492b + Hc/H2009 + **H5551 (sullam — ladder)** + H5324 + H776 + Hc/H7218a + H5060 + Hd/H8064 + Hc/H2009 + **H4397 (malakhei) + H430 (elohim) + H5927 (olim) + H3381 (yordim)**).

**Bron-eigen drie elementen**:
- **`sullam`** H5551 — **HAPAX in OT** (alleen Gen 28:12). Bron-eigen unieke woord-keuze.
- **`olim ve-yordim`** — op- en neerklimmen-formule. Cross-link Joh 1:51 (cluster D).
- **`malakhei elohim`** — engelen Gods (Hebreeuws plural).

**Genesis 28:13-15** [N1] — JHWH-belofte: `ani ieue elohei Avraham avikha ve-elohei Yitzchaq ha-aretz asher attah shokhev aleha lekha ettenenah u-le-zar'akha ... ve-hayah zar'akha ka-afar ha-aretz u-faratzta yamah va-qedmah ve-tzafonah va-negbah ve-nivrekhu vekha kol mishpechot ha-adamah u-ve-zar'akha` (drievoudige patriarchen-belofte: Abraham + Isaak + Jakob's zaad).

**Genesis 28:18-19** [N1] — `va-yiqra et shem ha-maqom ha-hu **Beit El** va-ulam Luz shem ha-ir la-rishonah` (H7121 + H4725 + H1008 + H199 + H3870 + H7223). **Bron-eigen naam-verandering plaats**: Luz → Bethel (`beit-el` — huis van El).

**Genesis 28:20-22** [N1] — Jakob's `neder` (gelofte H5088): als JHWH met mij is en mij beschermt + ik vredig terugkeer dan zal ieue mijn elohim zijn + deze steen huis-elohim + ik zal tienden geven. **Bron-eigen drievoudige voorwaardelijke gelofte** — eerste tienden-vermelding na Abraham (Gen 14:20). Cross-link `../B_cijfer/10.md` Cluster B.

### Cluster B — Gen 32:22-32 Pniel-worsteling + naamsverandering [N1]

**Genesis 32:24** [N1] (= MT 32:25) — `va-yivvater Yaaqov levaddo va-ye'aveq **ish** immo ad alot ha-shachar` (Hc/H3498 + H3290 + H905 + Hc/H79 + **H376 (ish — man)** + H5973a + H5704 + H5927 + Hd/H7837). **Bron-eigen unieke werkwoord `ye'aveq`** (H79 — worstelen, hapax).

**Genesis 32:28** [N1] — `va-yomer **lo Yaaqov yei'amer od shimkha ki im Yisrael ki sarita im elohim ve-im anashim va-tukhal**` (Hc/H559 + H3808 + H3290 + H559 + H5750 + H8034 + H3588a + H518a + **H3478 (Yisrael) + H8280 (sarita — gij hebt gestreden) + H430 + H376 + Hc/H3201**).

**Bron-eigen N1 expliciete naam-verandering-formule** + **bron-eigen woord-uitleg** `Yisrael` ↔ `sarita ... im elohim` (gij hebt gestreden met elohim). Werkwoord `sarah` H8280 (strijden) als wortel-uitleg.

**Genesis 32:30** [N1] — `va-yiqra Yaaqov shem ha-maqom **Pniel** ki ra'iti elohim panim el-panim va-tinnatzel nafshi` (H6121b + H7200 + H6440 + H413 + H6440). **Bron-eigen plaats-naam-uitleg** Pniel/Penuel (= aangezicht-El).

**Genesis 32:32** [N1] — `al ken lo yokhlu venei Yisrael et gid ha-nasheh asher al kaf ha-yarekh ad ha-yom ha-zeh` — etiologische uitleg dat Israelieten geen heupzenuw eten. **Bron-eigen narratief-historisch feit**.

### Cluster C — Gen 35:1-15 terugkeer-Bethel + bevestiging [N1]

**Genesis 35:1** [N1] — `va-yomer elohim el Yaaqov **qum aleh Beit El** ve-shev sham va-aseh sham mizbeach la-El ha-nire elekha be-vorchakha mi-pnei Esav achikha` (H559 + H430 + H413 + H3290 + H6965b + H5927 + H1008 + Hc/H3427 + H8033 + Hc/H6213a + H8033 + H4196 + Hl/H410 + Hd/H7200 + H413 + Hb/H1272 + Hm/H6440 + H6215 + H251). **Bron-eigen JHWH-opdracht** terugkeer-Bethel.

**Genesis 35:7** [N1] — `va-yiven sham mizbeach va-yiqra la-maqom **El Beit El** ki sham niglu elav ha-elohim` — Jakob bouwt altaar + noemt plaats `El Beit El` (`elohim` van het huis-elohim). **Bron-eigen N1 expliciete openbaring-bevestiging**.

**Genesis 35:9-10** [N1] — `va-yera elohim el Yaaqov od be-vo'o mi-Paddan Aram va-yvarekh oto va-yomer lo elohim **shimkha Yaaqov lo yiqra shimkha od Yaaqov ki im Yisrael yi·hyeh shemekha va-yiqra et shemo Yisrael**` (Hc/H7200 + H430 + H413 + H3290 + H5750 + Hb/H935 + Hm/H6307 + Hc/H1288 + H853 + Hc/H559 + Hl + H430 + H8034 + H3290 + H3808 + H7121 + H8034 + H5750 + H3290 + H3588b + H518b + H3478 + H1961 + H8034 + Hc/H7121 + H853 + H8034 + H3478). **Bron-eigen N1 expliciete bevestiging** van naamsverandering Yaaqov → Yisrael (eerder gegeven in Gen 32:28).

**Genesis 35:11-12** [N1] — JHWH-bevestigings-belofte: `peri u-rveh **goy u-qehal goyim** yi·hyeh mi-mekka u-melakhim me-chalatzeykha yetze'u ve-et ha-aretz asher natatti le-Avraham u-le-Yitzchaq lekha ettenennah u-le-zar'akha acharekha etten et ha-aretz` (H6509 + Hc/H7235 + **H1471a + Hc/H6951 + H1471a** + H1961 + Hm/H4480a + Hc/H4428 + Hm/H2504 + H3318). **Bron-eigen drievoudige patriarchen-keten** + meervoudige `goy + qehal goyim` + koningen-uit-Jakob.

**Genesis 35:14-15** [N1] — `va-yatzev Yaaqov matzevah ba-maqom asher dibber ito ... va-yiqra Yaaqov et shem ha-maqom asher dibber ito sham elohim **Beit El**` (Hc/H5324 + H4676 + Hb/Hd/H4725 + H834a + H1696 + H854 + Hc/H7121 + H3290 + H853 + H8034 + Hd/H4725 + H834a + H1696 + H854 + H8033 + H430 + H1008). **Bron-eigen tweede naam-bevestiging Bethel** — bron-eigen inclusio met Gen 28:19.

### Cluster D — Joh 1:51 NT-Bethel-Mensenzoon-citaat [N1]

**Johannes 1:51** [N1] — `kai legei autō amēn amēn legō hymin **apartē tou nyn opsesthe ton ouranon aneōgota kai tous angelous tou theou anabainontas kai katabainontas epi ton huion tou anthrōpou**` (G2532 + G3004 + G846 + G281 + G281 + G3004 + G5213 + G534 + G3568 + G3700 + G3588 + G3772 + G455 + G2532 + G3588 + **G32 (angelous) + G3588 + G2316 + G305 (anabainontas) + G2532 + G2597 (katabainontas)** + G1909 + G3588 + G5207 + G3588 + G444).

**Bron-eigen N1 expliciete christologische identificatie**:
- **`tous angelous tou theou anabainontas kai katabainontas`** — woord-voor-woord-parallel van Gen 28:12 `malakhei elohim olim ve-yordim`.
- **`epi ton huion tou anthrōpou`** — Mensenzoon ALS ladder-equivalent. **Bron-eigen N1 NT-tekst-eigen-uitleg** — ladder wordt vervangen door persoon Mensenzoon.

**Bron-eigen Joh 1:51 = enige NT-citaat** van Gen 28-Bethel-narratief. Direct christologische bridge.

### Cluster E — Bethel-cyclus parallellen in Gen [N1]

**Genesis 12:8 + 13:3** [N1] — Abraham bouwt altaar bij Bethel + roept JHWH-naam aan. **Bron-eigen voorganger-Bethel-feit** vóór Jakob.

**Genesis 35:6** [N1] — `va-yavo Yaaqov Luzah asher be-eretz Kena'an hi Beit El` — bevestiging dat Luz = Bethel. **Bron-eigen plaats-naam-keten**: Abraham-Bethel → Jakob-vertrek-Bethel → Jakob-terugkeer-Bethel.

**Bron-eigen drie-traps Bethel-cluster** in Genesis-corpus.

## Coherentie-toets

**Twee-getuigen drempel.** Cluster A: Gen 28:10-22 (13 verzen). Cluster B: Gen 32:22-32 (10 verzen, Pniel-cyclus). Cluster C: Gen 35:1-15 (15 verzen, terugkeer). Cluster D: Joh 1:51. Cluster E: Gen 12:8 + 13:3 + 35:6 patriarchen-cluster. Robuust.

**Verspreiding over genres.** Tora-narratief (Gen) + NT-evangelie (Joh). Beperkt corpus, NT alleen Joh 1:51 expliciet citeert.

**Wegnemingstoets.** Bij wegnemen Gen 28:12 valt sleutel-droom weg, maar Gen 35:1-15 terugkeer-bevestiging dragen Bethel-typologie. Bij wegnemen Gen 35 valt terugkeer-bevestiging weg.

**NT-OT verbinding (eerlijke beoordeling).**
1. **Joh 1:51 expliciete christologische bridge** ladder-engelen ↔ Mensenzoon. **N1 NT-tekst-eigen-uitleg**.
2. **Niet door tekst expliciet gelegd**: Bethel-vertrek + Pniel-worsteling + Bethel-terugkeer als typologisch reis-bekering-pad. **N2 structurele afleiding**.
3. **Niet door tekst expliciet gelegd**: Yaaqov → Yisrael naamsverandering als wedergeboorte-typologie. **N3-clue** (Joh 3:3-7 wedergeboorte-tekst spreekt geen specifieke Yaaqov-Yisrael-bridge).
4. **Niet door tekst expliciet gelegd**: drievoudige patriarchen-belofte (Abraham + Isaak + Jakob) gestructureerd als typologisch heilshistorisch model. **N3-clue** als systematische uitwerking.

## Waarschuwingen

**Cluster A `sullam`** H5551 — **HAPAX in OT**, alleen Gen 28:12. **Bron-eigen feit**. Niet over-claimen op specifieke "Christus = ladder"-typologie zonder Joh 1:51 als NT-bridge. Cluster D levert deze bridge wel expliciet.

**Cluster B `ish` Gen 32:24** — bron-eigen H376 (man). Tekst zegt **niet expliciet** "engel" of "JHWH" — ook al noemt Hosea 12:4 (= MT 12:5) de figuur retrospectief `malakh` (engel) en interpreteert Jakob zelf hem in Gen 32:30 als `elohim panim el-panim`. **N1 op woord-feit `ish`**, **N2 op specifieke identificatie**.

**Cluster B Pniel ↔ Penuel** — twee spelling-varianten van zelfde naam (H6439 + H6121b). **Bron-eigen tekst-feit**. Niet over-claimen op specifieke etymologische diepere lading.

**Cluster B Yaaqov → Yisrael** — bron-eigen naam-verandering. **Niet vermengen** met Christus-naam-typologie zonder NT-tekst-bridge. Yaaqov H3290 (hiel-grijper) ↔ Yisrael H3478 (hij-strijdt-met-El) is bron-eigen wortel-feit. **N1 woord-feit**, **N3-clue** op specifieke wedergeboorte-typologische uitwerking.

**Cluster C drievoudige naam-bevestiging Bethel** Gen 35:7 + 35:14-15 — bron-eigen feit. Specifieke "drievoudige bevestiging = goddelijk-typologisch"-uitwerking is **N3-clue**.

**Niet over-claimen op specifieke chronologische dating** Jakob-cyclus.
