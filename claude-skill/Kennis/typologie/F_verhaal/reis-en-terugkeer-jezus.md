## Hypothese (terughoudend gemaakt)

Tekst-eigen feiten. **Mattheüs 2:13-23** beschrijft Jezus' kindheids-reis-cyclus: vlucht naar Egypte (vss 13-14) + verblijf tot Herodes-dood (vs 15) + terugkeer uit Egypte (vss 19-21) + vestiging Nazaret (vss 22-23). **Bron-eigen drie expliciete profetie-vervulling-formules** binnen dit narratief: (1) Mat 2:15 citeert Hos 11:1 (`ex Aigyptou ekalesa ton huion mou`); (2) Mat 2:17-18 citeert Jer 31:15 (Rachel-tranen Bethlehem-context); (3) Mat 2:23 citeert ongespecificeerde profeten (`Nazōraios klēthēsetai`). Dubbele engel-droom-cyclus aan Jozef (vader van Jezus): eerste droom Mat 2:13 (vlucht-bevel), tweede droom Mat 2:19-20 (terugkeer-bevel).

NT-eigen typologie-claim. **Mat 2:15** maakt expliciet typologische identificatie: Jezus' uittocht uit Egypte vervult Hos 11:1's profetie over Israel-zoon. **N1 expliciete profetie-vervulling-formule**. **Mat 2:13-14 dubbele engel-droom** + Mat 2:19-20 dubbele engel-droom = bron-eigen vier engel-bezoeken aan Jozef in Mat 1-2 (1:20 + 2:13 + 2:19 + 2:22). Cross-link `../E_structuur/inclusio-mattheus.md` voor Mat-evangelist-citaat-cluster (5 expliciete profetie-vervullings-formules in Mat 1-2).

Interpretatieve framings. Dat Jezus' Egypte-reis typologisch model is voor "Israel-zoon-typologisch-vervuld in Jezus": **N1 op Hos 11:1-citaat in Mat 2:15**, **N2 op systematische uitwerking buiten dit specifieke citaat**. Dat Hos 11:1's oorspronkelijke context (Israel-zoon herinnerd aan Egypte-uittocht) profetisch op Jezus wijst: **bron-eigen Mat-redactie-feit** binnen NT-tekst, niet bron-eigen OT-Hos-context. Tekst-feit: Hos 11:1 is in OT-context retrospectief (verleden-tijd over Israel); Mat 2:15 leest het profetisch (toekomst-vervuld in Jezus). **N2 typologische lezing** van OT-retrospectie naar NT-typologische vervulling.

## Voorkomens (per cluster)

### Cluster A — Mat 2:13-14 vlucht naar Egypte (engel-droom 1) [N1]

**Mattheüs 2:13** [N1] — translit `anachōrēsantōn de autōn idou aggelos kyriou phainetai kat onar tō Iōsēph legōn egertheis paralabe to paidion kai tēn mētera autou kai pheuge eis Aigypton kai isthi ekei heōs an eipō soi mellei gar Hērōdēs zētein to paidion tou apolesai auto` (G402 + G2400 + G32 + G2962 + G2596 + G3677 + G2501 + G3004 + G1453 + G3880 + G3813 + G3384 + **G5343 (pheuge — vlucht)** + G125 + G2264 + G2212 + G3813 + G622).

**Bron-eigen drie elementen**:
- **`aggelos kyriou ... kat onar`** — engel JHWH in droom (parallel Mat 1:20 + 2:19 + 2:22 — viervoudig in Mat 1-2)
- **`pheuge eis Aigypton`** — bron-eigen vlucht-bevel naar Egypte
- **`apolesai`** G622 (verloren-doen) — Herodes-dreiging

**Mattheüs 2:14** [N1] — `ho de egertheis parelaben to paidion kai tēn mētera autou nuktos kai anechōrēsen eis Aigypton` (G1453 + G3880 + G3813 + G3384 + G3571 + G402 + G125). **Bron-eigen `nuktos`** ('s nachts) — bron-eigen feit van nachtelijk-vertrek.

### Cluster B — Mat 2:15 Hos 11:1 vervulling-citaat [N1]

**Mattheüs 2:15** [N1] — `kai ēn ekei heōs tēs teleutēs Hērōdou hina plērōthē to rhēthen hypo tou kyriou dia tou prophētou legontos **ex Aigyptou ekalesa ton huion mou**` (G2532 + G2258 + G1563 + G2193 + G5054 + G2264 + G2443 + G4137 + G4483 + G5259 + G2962 + G1223 + G4396 + G3004 + G1537 + G125 + G2564 + G5207 + G3450).

**Bron-eigen vier elementen**:
1. **`heōs tēs teleutēs Hērōdou`** — verblijf tot Herodes-dood (G5054 — sterven)
2. **Vervulling-formule** `hina plērōthē to rhēthen hypo tou kyriou dia tou prophētou legontos` (parallel Mat 1:22 + 2:17 + 2:23 — viervoudig in Mat 1-2)
3. **Citaat Hos 11:1**: `ex Aigyptou ekalesa ton huion mou` (uit Egypte heb Ik mijn zoon geroepen)
4. **Bron-eigen tekst-feit**: NT-citaat afwijkend van LXX (LXX heeft `metekalesa ta tekna autou`) — Mat 2:15 citeert dichter bij Hebreeuws `mi-Mitzrayim qarati li-vni`. **Bron-eigen Mat-redactie-keuze**.

**Hosea 11:1 (OT-bron)** [N1] — translit `ki na'ar Yisrael va-ohaveh·u u-mi-Mitzrayim qarati li-vni` (H3588a + H5288 + H3478 + Hc/H157 + Hc/Hm/H4714 + H7121 + Hl/H1121a). **Bron-eigen OT-context**: Israel-knaap-verleden + JHWH-liefde + uittocht-Egypte-roeping. **Niet profetisch in Hos-context** (verleden-tijd).

### Cluster C — Mat 2:16-18 Bethlehem-kindermoord + Jer 31:15 [N1]

**Mattheüs 2:16** [N1] — Herodes-reactie: `aposteilas aneilen pantas tous paidas tous en Bēthleem kai en pasin tois horiois autēs apo dietous kai katōterō` (G649 + G337 + G3956 + G3816 + G965 + G3725 + G1332 + G2736). **Bron-eigen kindermoord-feit** in Bethlehem + omgeving, kinderen onder twee jaar.

**Mattheüs 2:17** [N1] — vervulling-formule: `tote eplērōthē to rhēthen hypo Ieremiou tou prophētou legontos` (G5119 + G4137 + G4483 + G5259 + **G2408 (Ieremiou)** + G4396 + G3004). **Bron-eigen N1 expliciete attributie aan Jeremia**.

**Mattheüs 2:18** [N1] — Jer 31:15-citaat: `phōnē en Rama ēkousthē thrēnos kai klauthmos kai odurmos polus Rachēl klaiousa ta tekna autēs kai ouk ēthelen paraklēthēnai hoti ouk eisin` (G5456 + G4471 + G191 + G2355 + G2805 + G3602 + G4478 + G2799 + G5043 + G3870). **Bron-eigen vier-traps tranen-formule** `thrēnos + klauthmos + odurmos`.

**Jer 31:15 (OT-bron)** [N1] — bron-eigen OT-context Babel-ballingschap-Rachel-rouw, niet kindermoord-context. **Bron-eigen Mat-typologische lezing**.

### Cluster D — Mat 2:19-21 terugkeer uit Egypte (engel-droom 2) [N1]

**Mattheüs 2:19** [N1] — `teleutēsantos de tou Hērōdou idou aggelos kyriou kat onar phainetai tō Iōsēph en Aiguptō` (G5054 + G2264 + G2400 + G32 + G2962 + G2596 + G3677 + G5316 + G2501 + G125). **Bron-eigen tweede engel-droom** na Herodes-dood.

**Mattheüs 2:20-21** [N1] — engel-bevel: `egertheis paralabe to paidion kai tēn mētera autou kai poreuou eis gēn Israēl tethnēkasin gar hoi zētountes tēn psychēn tou paidiou ho de egertheis parelaben to paidion kai tēn mētera autou kai eisēlthen eis gēn Israēl` (G1453 + G3880 + G3813 + G3384 + G4198 + G1093 + G2474 + G2348 + G2212 + G5590).

**Bron-eigen drie elementen**:
- **`poreuou eis gēn Israēl`** (ga naar het land Israel) — terugkeer-bevel
- **`tethnēkasin gar hoi zētountes tēn psychēn tou paidiou`** (want zij die de ziel van het kind zochten zijn gestorven) — woord-voor-woord-echo van **Exo 4:19** waar JHWH tot Mozes zegt `methu kol ha-anashim ha-mevaqshim et nafshekha` (alle mannen die uw ziel zochten zijn gestorven). **Bron-eigen NT-typologische echo Mozes-Jezus**. **N1 expliciete intertekstualiteit** zonder formele citaat-formule.
- Letterlijke uitvoering Mat 2:21.

### Cluster E — Mat 2:22-23 vestiging Nazaret + derde profetie-citaat [N1]

**Mattheüs 2:22-23** [N1] — Jozef vestigt zich in Nazaret omdat Archelaüs in Judea regeert. Mat 2:23 vervulling-formule: `hopōs plērōthē to rhēthen dia tōn prophētōn hoti **Nazōraios klēthēsetai**` (G3704 + G4137 + G4483 + G1223 + G4396 + G3754 + **G3480 (Nazōraios)** + G2564).

**Bron-eigen specifieke kenmerken**:
- **`dia tōn prophētōn`** (door de profeten — meervoud) — **bron-eigen unieke meervoud-attributie**, geen specifieke profeet genoemd. Mat 1:22 + 2:5 + 2:15 + 2:17 noemen specifieke profeet of "de profeet".
- **`Nazōraios`** G3480 — bron-eigen woord-feit. Mogelijke OT-bridges: `netzer` H5342 (loot/twijg) Jes 11:1; `nazir` H5139 (afgezonderde) Num 6 + Ri 13:5; `notzeret` (bewaakte) Eze 6:12.
- **`Nazaret`** G3478 als plaats-naam — bron-eigen woord-feit. Verband tussen plaats-naam en profetie-formule is **bron-eigen Mat-redactie**.

### Cluster F — Mat 1-2 vier engel-droom-cyclus aan Jozef [N1]

**Bron-eigen viervoudige engel-droom-cyclus** aan Jozef in Mat 1-2:
- **Mat 1:20** — eerste droom: niet vrezen Maria + naam Jezus
- **Mat 2:13** — tweede droom: vlucht Egypte
- **Mat 2:19** — derde droom: terugkeer Israel
- **Mat 2:22** — vierde droom (`chrēmatistheis kat onar`): vestig in Nazaret

**Bron-eigen formule-overlap** `aggelos kyriou ... kat onar phainetai` (engel-JHWH-droom-verschijning) consistent over deze vier droom-momenten. Cross-link `./profetie-vervulling-bethlehem.md` Cluster D voor Mat 1-2 vijf-voudige profetie-vervullings-cluster.

### Cluster G — Mat 2:15 ↔ Hos 11:1 versus Joh 19:36 ↔ Exo 12:46 [N2]

**N2 cross-link**: Mat 2:15 citeert Hos 11:1 als profetie-vervulling, terwijl Hos 11:1 in OT-context **retrospectief** is over Israel-uittocht. Bron-eigen feit: NT-redactie identificeert Jezus typologisch als Israel-zoon. **Bron-eigen typologische omkering**: OT-tekst over Israel-volk wordt NT-typologisch toegepast op Christus-individu.

**Vergelijkbaar patroon**: Joh 19:36 citeert Exo 12:46 (`osteon ou syntribēsetai autou`) over Pesach-lam → toegepast op Jezus aan kruis. **Bron-eigen N2 typologische redactie-techniek** in NT.

## Coherentie-toets

**Twee-getuigen drempel.** Cluster A: Mat 2:13-14 (engel-droom 1). Cluster B: Mat 2:15 + Hos 11:1 OT-bron. Cluster C: Mat 2:16-18 + Jer 31:15 OT-bron. Cluster D: Mat 2:19-21 (engel-droom 2). Cluster E: Mat 2:22-23. Cluster F: viervoudige engel-droom Mat 1:20 + 2:13 + 2:19 + 2:22. Cluster G: vergelijkings-patroon Joh 19:36. Robuust.

**Verspreiding over genres.** NT-evangelie (Mat) + OT-profetie (Hos, Jer) + NT-evangelie cross-link (Joh). Volledig.

**Wegnemingstoets.** Bij wegnemen Mat 2:15 valt sleutel-citaat Hos 11:1 weg, maar drie-traps profetie-vervullings-formules dragen patroon. Bij wegnemen Hos 11:1 verdwijnt OT-bron maar Mat-typologische uitleg blijft.

**NT-OT verbinding (eerlijke beoordeling).**
1. **Mat 2:15 expliciete vervulling-formule** + woord-voor-woord-citaat Hos 11:1. **N1**.
2. **Mat 2:17-18 expliciete vervulling-formule** + Jer 31:15-citaat. **N1**.
3. **Mat 2:23 derde profetie-citaat-formule** met meervoud-attributie. **N1**.
4. **Mat 2:20 echo van Exo 4:19** (`tethnēkasin gar hoi zētountes`). **N1 expliciete intertekstualiteit** Mozes-Jezus-typologie.
5. **Niet door tekst expliciet gelegd**: Israel-zoon Hos 11:1 = Christus-Zoon Mat 2:15 als systematische bril. **N2 structurele afleiding** (de citaat zelf is N1, de breder typologische lezing N2).
6. **Niet door tekst expliciet gelegd**: drie reizen-en-terugkeer-cluster (Jakob + Jozef + Jezus). **N2 structurele afleiding**.

## Waarschuwingen

**Cluster B Hos 11:1 ↔ Mat 2:15** — bron-eigen feit dat Hos 11:1 in OT-context **retrospectief** is over Israel-uittocht (verleden-tijd `qarati` — heb Ik geroepen). Mat 2:15 leest het **profetisch-typologisch**. **Bron-eigen NT-redactie-keuze**. Niet over-claimen op specifieke "dubbel-vervulling-systeem" zonder erkenning dat de OT-context retrospectief is.

**Cluster C Jer 31:15 ↔ Mat 2:18** — bron-eigen feit dat Jer 31:15 in OT-context Babel-ballingschap-Rachel-rouw betreft. **Bron-eigen Mat-typologische lezing**. **Niet over-claimen** op specifieke "dubbele profetie-vervulling-typologie".

**Cluster E Mat 2:23 `Nazōraios`** — bron-eigen feit dat tekst geen specifieke OT-vers citeert. Mogelijke OT-bridges (Jes 11:1 `netzer`, Num 6 `nazir`) zijn **interpretatief**. **N1 op Mat-redactie-formule**, **N3-clue op specifieke OT-bridge**.

**Cluster A `pheuge eis Aigypton`** — bron-eigen vlucht-richting. **Niet over-claimen** op specifieke "Egypte = ballingschaps-typologisch" zonder specifieke tekst-bridge. Bron-feit: Egypte als asielplaats voor Jezus-kind, parallel Mozes-vlucht naar Midian (Exo 2:15), parallel Jakob-vlucht naar Charan (Gen 28).

**Niet over-claimen op specifieke chronologie** Herodes-dood + terugkeer-tijdsmoment.

**Cluster F vier engel-droom-cyclus** — bron-eigen feit. Specifieke "vier = volheid-getal-typologie" voor Jozef-droom-cyclus is **N3-clue**, geen tekst-bridge.
